# 拼音魔法轮盘 · FanerArt

用于中文课堂的三圈拼音轮盘：外圈声母，中圈规范拼写片段，内圈四声。点击后同时转动，并停在白名单内的有效带调音节。

在线版本：https://faner-pinyin-wheel.merrypig128.chatgpt.site

## 使用

直接打开 `index.html`，或使用静态文件服务器。不需要安装依赖或构建。

- 点击「开始旋转」，或者在页面空白处按空格。
- 学生先拼读，再点击「揭晓拼音」。
- 支持全屏、音效开关、最近 12 次记录和重新开始。
- 响应式界面，适用于手机、电脑和教室投影。

## 文件

- `index.html`：页面结构。
- `style.css`：样式和响应式布局。
- `app.js`：绘制轮盘、动画、随机抽取和声调标注。
- `data.js`：404 个不带调音节、1389 个带调候选；按教学组合白名单筛选，并用 pypinyin 字音数据筛选声调。

y、w 为教学拼写便利，放入外圈。零声母用「零」表示；中圈使用可直接组成规范拼写的片段，例如 w + eng → weng、j + u → ju。部分字典收录读音较生僻，适合由教师进一步筛选；不收轻声与儿化扩展音节。

## GitHub Pages

把此目录文件放在仓库根目录，在仓库的 Settings → Pages 中选择从 `main` 分支的根目录发布。

## 数据来源

声调筛选使用 pypinyin 项目的字音字典（https://github.com/mozillazg/python-pinyin），不需要在运行游戏时加载该项目。
